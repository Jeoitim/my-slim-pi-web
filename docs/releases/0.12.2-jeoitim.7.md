# My Slim Pi Web v0.12.2-jeoitim.7

本版沿用 pi-web 0.12.2 基线和 Pi SDK 1.4.0，补齐桌面启动源码包，并提供桌面 Web 密码设置。

- 修复启动包漏收 Node 自动判断格式的 JavaScript：启动资源从 1,360 个模块补齐到 2,071 个，保留 CommonJS、ESM、模块身份和资源路径语义。动态扩展和未知依赖仍使用普通加载。
- 新增构建覆盖检查：实际启动后端并访问首页及初始查询接口，要求模块源码散读为零，单独记录 Next 数据清单读取；缺失、损坏或过期的启动资源仍可回退。
- 设置 → 桌面应用中可填写 Web 登录密码，经系统加密保存，启动时自动注入后端，无需从终端设置环境变量。已有 `PI_WEB_PASSWORD` 优先，界面不回显明文。
- 保存、修改和删除密码会明确重启后端；有活动工作时先确认，取消不改密文。修改使旧登录失效，删除同时关闭本地 Web 入口。系统安全存储不可用时拒绝明文降级。
- 新增仓库清理脚本 `clean-local.ps1`，默认预览，`-Execute` 清除已知中间产物，保留依赖、配置和桌面安装包；拒绝删除跟踪文件和不安全的链接路径。

2026-10-27，用户实际使用后确认启动速度显著改善、应用已完全可用。慢启动排查曾发现 676 次 JavaScript 散文件读取累计约 22.7 秒。修复后的三次热缓存独立进程启动，界面可交互时间为 2.32 / 1.96 / 1.88 秒；用户反馈是实际使用验收，不等同于新的受控冷启动秒数或加速比例。

## 下载与安装

- Windows x64：`My.Slim.Pi.Web.Setup.0.12.2-jeoitim.7.exe`。
- Linux x64：原生构建成功时提供 `My.Slim.Pi.Web-0.12.2-jeoitim.7.AppImage`，运行前赋予执行权限。
- 用附件中的同名 `.sha256` 文件核对下载内容。完全退出旧版后运行安装包，保留现有 AgentRoot 和用户配置。
- 设置 Web 密码后重新登录，再启用“本地 Web 入口”。密码变更会中断运行任务、终端和待处理审批，请按界面提示操作。

本地已验证 24 项桌面测试、类型和 Lint、鉴权及权限边界、实际 Windows 打包界面、终端、动态 TypeScript 扩展、系统加密密码恢复和改密/删除流程。完整 Windows 测试仍有路径、MCP 和终端计时兼容性失败，未宣称全部通过。发布工作流另行在 Linux 执行完整检查，并原生构建与校验发布附件；Linux 图形桌面、macOS 和公网 Cloudflare 不作为本次人工验收范围。安装包目前未签名。
