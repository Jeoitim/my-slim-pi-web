# My Slim Pi Web v0.12.2-jeoitim.5 — local performance candidate

This candidate keeps the reviewed upstream baseline and Pi SDK versions from `.4`.

- Production startup uses a portable Node module compile cache generated during the build with the bundled Node runtime, rather than waiting for the user's first launch to populate it. Missing or stale caches fall back to ordinary module loading.
- Deployment dependencies omit type declarations and JS/TS source maps. Executable TypeScript extensions, templates, licenses, native terminal resources and package metadata remain available. Third-party installed stack traces no longer have those source maps.
- Backend status records Next loading/preparation durations separately. Startup and installer-payload comparison tools keep reproducible local reports.

The installer remains self-contained and uses the existing AgentRoot. No upstream updater, new Agent backend, background autostart or antivirus exclusions are introduced. See [performance measurements](../desktop-performance.md) for actual results and verification limits. Local packaging is not a GitHub release.
