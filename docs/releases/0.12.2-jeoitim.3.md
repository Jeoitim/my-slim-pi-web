# My Slim Pi Web v0.12.2-jeoitim.3

基于已审查的 pi-web 0.12.2，提供 My Slim Pi Web 的桌面发行版。本次发行包含 fork 自上游基准以来的桌面宿主与界面改动。

## 下载与安装

- Windows x64：下载 `My Slim Pi Web Setup 0.12.2-jeoitim.3.exe` 并运行安装。
- Linux x64：若 Release 附有同版本 `.AppImage`，执行 `chmod +x <文件名>.AppImage` 后运行。
- 各安装包旁附有同名 `.sha256` 文件，可用于核对下载内容。
- 安装包内含 Node.js 24、npm 和 npx；运行桌面应用无需另装 Node.js。

## 本版变化

- 新增 Electron 桌面宿主；聊天、会话、权限、终端和扩展仍由原有 Next.js / Pi 后端处理。桌面内部连接使用本机临时端口和签名身份，外部控制默认关闭。
- 桌面窗口增加启动进度页、失败重试页、原生标题栏控件及关闭时的活动任务提示。
- 为正文、代码、输入框、文件预览和终端增加右键操作；复制动作接入系统剪贴板。
- 为子代理任务加入桌面 Fleet 列表和 Inspector 视图，扩展交互继续沿用 Pi 的请求语义。
- 修复覆盖安装后可能读取旧 Next.js 路由缓存的问题，桌面资源在独立 `.desktop/` 目录构建。
- fork 版本和更新入口与上游分离，避免提示安装上游产品覆盖本发行版。

## 兼容性与验证

本版本已完成 Windows x64 隔离构建、NSIS 打包和打包目录应用回归；此前版本有实际安装回归记录，见 [桌面验证记录](https://github.com/Jeoitim/my-slim-pi-web/blob/v0.12.2-jeoitim.3/docs/desktop-validation.md)。本 tag 的 GitHub Actions 会重新执行代码检查与 Windows/Linux 原生打包；Windows 包通过校验后才发布，Linux 打包成功时附上 AppImage。Linux AppImage 的打包成功不等于已在所有 Linux 发行版上完成图形界面验收。macOS 未包含在本次发行中。安装包目前未签名。

## English

This fork release is based on reviewed pi-web 0.12.2. It adds an Electron desktop host while keeping the existing Next.js/Pi backend for sessions, permissions, extensions, and the terminal. It includes startup and failure screens, native window controls, clipboard and context menus, subagent views, isolated desktop build output, and a fix for stale packaged route caches.

Download the Windows x64 NSIS installer and compare its SHA256 file. If a Linux x64 AppImage is attached, verify its SHA256 file before running it. Both bundles include Node.js 24, npm, and npx. This version passed local Windows packaging and unpacked-app checks; an earlier version passed an installed-app check. The release workflow builds both targets natively and includes Linux when packaging succeeds. Linux desktop behavior across distributions and macOS are outside this release's verified scope. Packages are unsigned.
