# My Slim Pi Web 0.13.0-jeoitim.1

同一个 My Slim Pi，浏览器与桌面两种入口。

**使用前请先安装并初始化 [My Slim Pi CLI](https://github.com/Jeoitim/my-slim-pi#安装)。Web UI 与桌面应用依赖该项目，不能脱离它独立使用。** 桌面包内置 Node.js 24，但不会代替 CLI 的资源安装、扩展或模型配置。当前适配 Pi 1.4.0。

## 本版变化

- 集成上游 pi-web 0.13.0，更新会话续期、压缩期间消息排队、发送失败草稿恢复、Debug 状态查看、手机输入区等功能；继续保留 My Slim Pi 的权限、工具和任务代理所有权。
- 处理过程默认从开始时折叠，最新一行沿用原有思考或工具卡片样式，保留滚动提示；展开后限制过程区域高度，任务完成后隐藏单行预览。“设置 → 常规 → 对话”可关闭折叠，恢复原有平铺显示。
- 修复桌面终端的离线连接判断和留白区输入焦点，自动检测系统 Shell，可在终端头部切换 PowerShell、CMD、Git Bash 等已安装 Shell。
- 修复桌面对话输入框右键后选中文字消失，鼠标打开菜单时保留可见选区，复制、粘贴和键盘菜单继续可用。
- 精简桌面启动页，仅保留蓝色 Pi 图标、产品名和加载条动画。
- 修复桌面“完整历史”新窗口白屏：正文、思考、工具记录、图片及历史分支正常渲染，支持刷新，也兼容启用 Web 密码的情况；历史窗口与主界面的存储和桌面权限隔离。
- README 补充蓝色 Pi 标志、产品介绍、实际桌面截图、CLI 安装前提、下载与日常使用说明。

## 下载与安装

| 系统 | 文件 |
| --- | --- |
| Windows x64 | `My.Slim.Pi.Web.Setup.0.13.0-jeoitim.1.exe` 及同名 `.sha256` |
| Linux x64 | 原生构建成功时提供 `My.Slim.Pi.Web-0.13.0-jeoitim.1.AppImage` 及同名 `.sha256` |

1. 先完成 [My Slim Pi CLI 安装](https://github.com/Jeoitim/my-slim-pi#安装) 和模型配置，默认 Agent 目录为 `~/.pi/agent`。
2. 下载对应平台的附件，并按同名 `.sha256` 文件核对校验和。
3. 完全退出旧版应用后安装并启动；Linux AppImage 先赋予执行权限。自定义 Agent 目录时，启动前设置 `PI_CODING_AGENT_DIR`。

现有 Agent 数据与用户配置继续保留。安装包当前未签名；Linux 图形桌面、macOS 与公网 Cloudflare 环境不计入本次 Windows 人工验收范围。

## 验证范围

本地 Windows 已验证隔离生产构建、捆绑 Node 24.22.1 和 PTY、26 项桌面单元检查、类型与 Lint；实际打包应用验证了完整历史在无密码和有密码时的正文、思考、工具、内嵌图片、分支切换、刷新、窗口隔离与退出清理。启动源码包包含 2,073 个模块，真实后端及三个启动入口的单个模块源码读取为 0，Next VM 数据清单读取另计 3。

终端、折叠交互、选区和启动页分别有专项验收记录。完整 Windows Web 套件仍有已复现的基线平台差异，未将其记为全绿；此前上游集成和折叠功能的 Linux CI 结果与本次发布工作流分开记录。发布附件由本次 GitHub 工作流重新构建并校验，本地安装包的哈希不能代替发布附件的校验值。
