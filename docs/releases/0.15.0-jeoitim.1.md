# My Slim Pi Web 0.15.0-jeoitim.1

本版整合 pi-web 0.15.0，并适配 My Slim Pi CLI 1.5.0。使用前请先安装并初始化 [My Slim Pi CLI](https://github.com/Jeoitim/my-slim-pi#安装)；桌面包内置 Node.js，但不代替 CLI 资源、扩展和模型配置。

## 本版变化

- 整合上游 Web 更新，并保留 My Slim Pi 的权限、工具、扩展和现有 Agent 后端。
- 创建侧边对话时继承主对话当前的 My Slim Pi 权限模式。之后各对话可以分别切换权限模式，操作继续受对应模式与现有审批规则约束。
- 保留处理过程折叠、桌面终端及 Shell 切换、输入框右键选区和独立完整历史窗口等功能。
- 适配 CLI 1.5.0 的依赖和 MCP 连接，修复连接准备期间可能发生的时序问题。

## 下载与安装

| 系统 | 文件 |
| --- | --- |
| Windows x64 | `My.Slim.Pi.Web.Setup.0.15.0-jeoitim.1.exe` 和同名 `.sha256` |
| Linux x64 | 原生构建成功时提供 `My.Slim.Pi.Web-0.15.0-jeoitim.1.AppImage` 和同名 `.sha256` |

1. 安装 My Slim Pi CLI 1.5.0，完成初始化与模型配置。
2. 下载对应平台的附件，并使用同名 `.sha256` 核对下载文件。
3. 完全退出旧版应用后运行安装包；Linux AppImage 需先赋予执行权限。自定义 Agent 目录时，启动前设置 `PI_CODING_AGENT_DIR`。

安装包未签名，Windows 可能显示 SmartScreen 提示。Linux 图形桌面及 macOS 未在本次本机验收中验证。

## 验证范围

本地 Windows 完成类型检查、Lint、桌面与权限检查，以及完整自动化测试；使用打包后的桌面应用验证了设置、文件、终端、完整历史和输入框等功能。真实后端的启动源码读取覆盖检查通过。侧边对话使用真实 CLI 验证了权限继承及审批处理。旧版安装修复钩子通过隔离测试；本版安装包尚未在用户现有安装上执行真实升级验收。

GitHub Release 附件由发布工作流重新构建，校验值以附件旁的 `.sha256` 为准。
