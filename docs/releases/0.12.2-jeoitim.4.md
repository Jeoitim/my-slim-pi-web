# My Slim Pi Web v0.12.2-jeoitim.4

本次例行维护基于 pi-web 0.12.2 的 `e533d9b`，将七个 Pi SDK 包统一升级并精确固定到 1.4.0，配合 My Slim Pi 的 Pi 1.4.0 分发使用。上游发布版本仍为 0.12.2，因此递增 fork 修订号为 `.4`。

## 本版变化

- 集成上游六项修复：后台页面释放空闲事件流、worktree 临时 Git 错误不入缓存、删除模型供应商时清除重命名记录、会话实时活跃时间、保存 models.json 时保留符号链接，以及 macOS 新会话快捷键。
- 适配远程页面的会话续租；My Slim Pi 扩展持有后台任务时，页面继续接收事件。续租仍受登录、Host 和跨站请求校验保护，不启动 Agent 或执行命令。
- 真实扩展集成测试改用新版原生 Web 工具，支持配置启用与按需启用。
- 修复测试中的 Windows 文件 URL、CRLF 换行和后台 MCP 连接时序问题。

## 下载与安装

- Windows x64：发布后下载 `My.Slim.Pi.Web.Setup.0.12.2-jeoitim.4.exe`。
- Linux x64：原生打包成功后提供 `My.Slim.Pi.Web-0.12.2-jeoitim.4.AppImage`，赋予执行权限后运行。
- 使用安装包旁的同名 `.sha256` 文件核对下载内容。桌面包自带 Node.js 24、npm 和 npx；Agent 配置继续使用已有 My Slim Pi 安装。

## 验证范围

本次完成 Linux 全量测试（2889 通过、2 跳过、0 失败）、Windows/Linux 真实权限集成（各 9/9）、Windows 受影响回归（77/77）、类型与 Lint、桌面隔离构建、打包目录应用回归，以及生产后端认证/续租/SSE 验证。详情见 [兼容性报告](https://github.com/Jeoitim/my-slim-pi-web/blob/v0.12.2-jeoitim.4/docs/compatibility.md)。验证使用隔离的 AgentRoot 和测试会话；没有使用个人模型凭据或执行付费模型请求。Windows 全量套件仍有平台假设及 MCP/PTY 失败，未记为全绿。桌面隔离构建不覆盖开发用的 `.next/`。

实际 Cloudflare Tunnel/Access 公网链路、Linux 图形桌面运行及 macOS 未在本次本地验收范围内。安装包未签名。GitHub Release 由 tag 工作流在检查及原生构建通过后分发，本地生成安装包不等于已远程发布。
