# My Slim Pi Web 0.13.0-jeoitim.2

本版将 My Slim Pi 后台模型设置整合到原生子代理编辑页。

- “设置 → 子代理”恢复上游的左右分栏界面，直接查看子代理说明、提示词和配置详情，选择模型与思考级别。
- 审批模型与 Hermes 总结模型在同一页管理，无需先创建对话，不再弹出终端菜单或把 Show details 写入对话。
- “AUTO / ACT 人工审批提醒”移到“设置 → 常规 → 权限审批”，保存到原有 CLI 偏好，ASK 仍逐次等待审批。
- 模型变更保留 CLI 的其他字段和提示词；Hermes 继续使用原配置及即时更新事件。CLI 工具、运行选项、权限与任务代理授权继续由原项目管理。

使用前仍须安装并初始化 [My Slim Pi CLI](https://github.com/Jeoitim/my-slim-pi#安装)，当前适配 Pi 1.4.0。

验证范围与实际构建记录见 [原生子代理设置验证](../agent-settings-validation.md)。
