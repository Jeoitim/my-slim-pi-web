# My Slim Pi Web 0.18.0-jeoitim.1

本版整合 pi-web 0.16.0 至 0.18.0，以及 0.18.0 发布后的 9 个提交。适配 [My Slim Pi CLI 1.6.0](https://github.com/Jeoitim/my-slim-pi#安装)，桌面包自带 Node.js 24、npm 和 npx。请在启动前完成 CLI 初始化和模型配置。

## 本版变化

- 折叠的过程信息新增费用汇总。运行中仍显示最近一条过程记录，关闭折叠后恢复完整列表。
- 原工作目录已不存在时，可选择目录后将会话另存为新会话。会话导出使用独立临时目录，桌面完整历史继续在隔离窗口中打开。
- 修复 Windows 终端关闭和触屏自动聚焦行为，保留桌面 Shell 切换和输入框右键选区。
- Web 和桌面继续使用 CLI 的权限、工具和子代理。侧边对话继承来源对话的当前权限模式，随后可独立切换。

## 下载与安装

| 系统 | 文件 |
| --- | --- |
| Windows x64 | `My.Slim.Pi.Web.Setup.0.18.0-jeoitim.1.exe` 和同名 `.sha256` |
| Linux x64 | 原生构建成功时提供 `My.Slim.Pi.Web-0.18.0-jeoitim.1.AppImage` 和同名 `.sha256` |

下载后用同名 `.sha256` 核对文件。Windows 请完全退出旧版再运行安装包。Linux 请先赋予 AppImage 执行权限。使用自定义 Agent 目录时，请在启动前设置 `PI_CODING_AGENT_DIR`。

## 验证范围

在 Windows 和 Linux 的隔离环境中加载真实的 CLI 1.6.0 资源，验证权限切换、子会话继承、会话恢复、逐次审批和原生 Shell。Web 浏览器端到端、生产 HTTP/SSE 和 Windows 桌面后端启动覆盖检查均已通过。Windows 全量回归有一项 npm 回环测试超时，单项复测通过。

Windows 安装包未签名，系统可能显示 SmartScreen 提示。现有用户安装的原地升级、Linux 图形桌面和 macOS 未在本机执行验收。附件由 GitHub 发布工作流按 tag 重新构建，文件校验值见同名 `.sha256`。
