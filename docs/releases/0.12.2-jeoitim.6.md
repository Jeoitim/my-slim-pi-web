# My Slim Pi Web v0.12.2-jeoitim.6 — desktop startup optimization

本版沿用 pi-web 0.12.2 基线和 Pi SDK 1.4.0，集中优化桌面冷启动和安装包文件数量。

- Build-time, portable module resolution index for packaged code, keyed by parent module, request and export conditions.
- A compressed startup JavaScript source pack loaded in memory, preserving original module URLs, class identity, resource paths and original-file fallback. User extensions and unknown dependencies continue through the normal loader.
- Normal fast startup no longer reads thousands of independent V8 bytecode-cache files. Missing, corrupt or stale startup assets fall back to ordinary loading. The assets bind to Node, platform, architecture, application version and build ID.
- Remove known PTY prebuilds for foreign platform/architecture combinations; retain the bundled Node target and unknown native resource folders.
- Keep the last 20 sanitized backend startup measurements in Electron's userData directory, so a slow first launch is not overwritten by immediate warm tests.

On 2026-10-25, after installing `.6` and launching it several times over two days, the user confirmed that cold-start speed meets expectations and authorized pushing the optimization. The controlled process-launch comparison recorded a 34% reduction in median time to interactive UI (3.21 to 2.11 seconds); the real-use feedback is not a new timed benchmark.
