# Windows 安装器与子代理排版修复

## 安装器

electron-builder 26.15.3 默认的 PowerShell 检查使用安装路径的裸前缀匹配，且加载用户 profile。它会把目录内的任意可执行程序、路径前缀相同的相邻安装目录也算作应用；从安装目录运行安装器或原地运行卸载器时，自身也能触发该条件。其停止逻辑沿用相同范围。这些是源码可复现的误报条件，不能据此断定用户当时属于哪一种情况。

通过官方 `nsis.include` / `customCheckAppRunning` 接点替换进程检查，没有修改第三方依赖。辅助脚本使用系统 PowerShell 5.1、禁用 profile、按参数传递目录。只识别目标主程序和 `resources/` 内的程序，排除当前安装器 PID；停止前复核 PID、路径与创建时间，防止进程号复用。返回值分别表示运行、未运行、检查失败，不把异常当作运行。交互确认后只停止本次安装持有的程序；静默模式发现活动实例则返回 2。

`electron/scripts/installer-process-check.ps1` 启动自建休眠程序，不操作个人应用。检查内容：

- Windows PowerShell 5.1 与 PowerShell 7：主程序、后台 Node、安装器/卸载器、相邻目录和其他安装副本的识别；只停止目标应用及后台，保留其余进程；排除指定自身 PID；拒绝相对目录和磁盘根目录。
- 实际 NSIS 安装/卸载钩子：从安装目录启动，路径含中文、空格、单引号和 `&`，无应用时正常继续；有实际应用时，静默执行返回取消且保留应用。
- 隔离钩子不写产品注册表、不建快捷方式、不安装或卸载个人应用。不能代替真实系统上的覆盖安装验收；旧版卸载器、系统组策略或权限限制仍可能需要手动关闭/以相同权限运行。

上述检查通过。桌面单元检查 26/26、相关设置/国际化检查 19/19、类型检查、Lint 及通用清理脚本安全回归通过。
