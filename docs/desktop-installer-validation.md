## 诊断与变更

用户报告 C 盘默认目录 `%LOCALAPPDATA%\Programs\MySlimPiWeb` 仍提示“应用无法关闭”。检查时目录内的宿主版本为 `.1`，没有发现目标目录中的运行进程；26 个原生程序/模块以及全部 16,081 个文件均通过可写检查。原目录只作读取和打开检查，没有写入文件内容或执行卸载。

electron-builder 26.15.3 的 NSIS 源码有三条路径使用同一个 `appCannotBeClosed` 文案：进程无法停止、旧卸载器反复失败、7z 临时目录复制失败。7z 分支最终重试还明确忽略直接解压错误。此前只测试进程钩子，不能证明整个安装流程正常。独立目录中的原始完整 7z 解压与复制也能完成，因此不能将用户那次失败断言为某个进程或已确认的 Windows 错误码。

通过受支持的 `useZip: true` 和 `differentialPackage: false` 切换到直接 ZIP 解压及返回值检查，避开临时复制和忽略错误的分支。项目没有差分自动更新器。目标目录内的进程检查继续保留；排除安装器自身和其他安装副本，关闭前复核 PID、路径及创建时间。静默安装发现实际运行实例时返回取消，不自动停止任务。没有修改第三方依赖源码。
