2026-10-30，Windows x64、Node.js 24.22.1，版本 `0.12.2-jeoitim.8`，上游产品基线仍为 0.12.2。

## 行为

沿用 Web 的“处理详情”和既有消息、思考、工具卡片。正在运行的一轮从第一条思考或工具调用起默认折叠，下方一行预览跟随最新活动更新，工具区分运行中、成功和失败；部分输出不误报成功。点击摘要或预览可展开。展开区最大 420px，且不超过可用窗口高度的一半，内容在内部滚动，支持键盘滚动。

流式最终文字与图片、已完成的最终回答、供应商错误及输出截断提示继续显示在过程区外。按最后一条助手消息决定终点，避免错误前的中间文字被当成最终回答、后续工具掉到折叠区外。手动展开跨工具步骤和运行完成保留，刷新历史恢复默认折叠；搜索定位仍可强制展开。

实现仅在 Web 显示层分组，没有安装 pi-tidy、复制它的终端原型补丁或修改 SDK、工具执行、权限与会话格式。参考了 CLI 仓库及实际固定的 pi-tidy 0.4.11 的分组和运行提示。

## 构建产物与打包运行限制

功能源码提交为 `52cad9c`。最终 `npm run desktop:build` 和 `npm run desktop:pack` 均成功；随后修改仅涉及验收脚本和本记录。安装包位于 `dist-desktop/My.Slim.Pi.Web.Setup.0.12.2-jeoitim.8.exe`，219,713,904 字节（约 209.5 MiB），旁有同名 `.exe.sha256` 文件。SHA-256：

```text
c30a663f55ef10423fccca6408072961be0f34d2b85734946c23232abbd9d753
```

实际运行 `win-unpacked` 产物，核对其版本及生产 BUILD_ID 与最终构建一致；没有执行安装器安装或远程发布。构建保留导出路由既有动态依赖表达式警告，没有影响产物生成。日志在忽略目录 `.local/tidy-desktop-build-final.log`、`.local/tidy-desktop-pack.log`。

`npm run test:desktop:packaged` 的功能断言通过，但完整脚本仍未通过：其 Playwright 调试连接附着时，宿主在退出阶段超过 30 秒。诊断观察到后端监督器结束、Electron 发出 `quit`，但进程未退出；不能据此宣称完整桌面 E2E 全绿。本次修正旧脚本中与 `6788bc0` 冲突的设置接口断言，把退出期限放到 `app.close()` 外，明确验证退出码，并仅在所有退出检查通过后输出 `passed: true`。测试创建的终端先自然结束并移除，未改产品权限或退出逻辑。

另外用不附加 Node 调试器的独立产物启动复测：打开同一隔离夹具会话，创建真实终端、结束并移除它，预定通过现有 preload `quit` 接口退出；先断开浏览器 CDP 调试连接，再执行退出。结果退出码 0，后端监听关闭（`.local/tidy-native-quit-check-final.log`）。保留调试连接的对照会超时。因此当前证据支持调试连接相关的验收限制，但尚未修复该脚本与宿主的交互；不将这次退出问题归因于折叠改动，也不声称已证明所有退出场景正常。所有本次验收进程均已结束。

## 全量测试的限制

修改期间执行了全量 Web 套件：2,853 项，2,785 通过、47 失败、21 跳过。`mcp-read-only-policy.integration` 和 `subagent-mcp.integration` 再次保留进程不退出，结束本次运行的这两个已确认进程后获得汇总，不能记为自然结束或全绿。使用了 `--test-timeout=90000`，但它没有结束这两处残留进程。
