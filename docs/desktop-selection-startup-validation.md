# 桌面选区与启动页修复验证

2026-10-30，Windows x64，版本保持 `0.13.0-jeoitim.1`。

## 输入框右键

在此前同版本的真实打包应用中复现：输入 `Start 选择这段文字 finish`，选中索引 6–12 后右键输入框空白处，选区会变成 19–19，复制不可用。右键菜单收到 `contextmenu` 前，Chromium 的鼠标默认行为已经移动了光标。

修复在捕获阶段保留非空输入框选区。鼠标打开的文本菜单保留输入框焦点和可见高亮；菜单点击、复制、粘贴和全选继续使用原有剪贴板通道。键盘打开的菜单仍正常获取焦点，其他侧边栏菜单默认行为不变。

真实桌面回归通过：

- 右键点选中文字及输入框空白处，选区均保留 6–12，系统剪贴板精确得到“选择这段文字”。
- 选中高亮在菜单显示时保持可见；普通左键仍能定位光标。
- Escape 保留选区；方向键和 Enter 可执行复制；Shift+F10 正常将焦点移入菜单。
- 菜单打开时的普通字符和删除键不修改草稿，Enter 不发送草稿。
- 输入框替换粘贴、全选复制、正文/代码/文件复制、终端缓冲区复制及原生粘贴均通过。
- 终端明暗菜单、窗口边缘布局和正文之外的菜单层级检查通过；中文菜单实际使用 Microsoft YaHei UI。

脚本为 `electron/scripts/clipboard-check.mjs`，使用独立 AgentRoot 和桌面配置。原系统剪贴板内容只在主进程内存中备份并恢复，不写日志或文件，不调用付费模型。
