# Noto Sans Mono

The original variable-font subsets from the validated desktop build are bundled here so production builds do not fetch Google Fonts. Font bytes, weight range (100–900), Unicode ranges and fallback metrics are preserved. Chinese text continues to use the application's existing Microsoft YaHei / Noto Sans SC fallbacks.

Upstream: https://github.com/google/fonts/tree/main/ofl/notosansmono
